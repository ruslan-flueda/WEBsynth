# Аудит и рефакторинг — 13 октября 2026

Проверена чёрная версия WEBsynth из `websynth-v2-pre-nay`. Светлая Orchestra и синхронизированные материалы проекта не входят в этот рефакторинг.

## Найдено и исправлено

| Проблема | Изменение |
| --- | --- |
| Несколько действий в строке, короткие неоднозначные имена | Раскрыты блоки JS/CSS, введены именованные события и параметры, добавлен `.editorconfig` |
| Исходники находились непосредственно в `dist` | Добавлены `src`, воспроизводимое копирование сборки и проверка равенства исходников/результата |
| Монолитный аудиодвижок смешивал граф, синтез и транспорт | Разделён на `engine`, `channel`, `effects`, `synthesis`, `voices` |
| UI смешивал создание карточек, обработчики и сообщения | Разделён на `ChannelView`, `App` и точку входа `main.js` |
| Все музыкальные партии лежали в одном файле | Семь отдельных файлов паттернов, общий формат события и Shuffle |
| Эффекты выбирались по отображаемым надписям | Ключи параметров отделены от подписей |
| BPM хранился в общем изменяемом объекте | Темп принадлежит экземпляру секвенсора и передаётся движку |
| Паттерн и Shuffle делили одну отметку ожидания | Независимые очереди и отметки времени |
| Solo мог отменить запланированное переключение gain канала | Раздельные pattern gate и solo gate |
| Ошибка запуска затиралась финальным render | Сообщение сохраняется до следующего действия |
| Фоновые генераторы Chords не останавливались | Все источники отслеживаются и завершаются через общий механизм |
| Старт мог завершиться после ухода со страницы | Stop отменяет ожидающий асинхронный старт |
| Повторный Play мог кратко показывать старый номер такта | Позиция отображения сбрасывается при запуске |
| Shuffle пересчитывался на каждой шестнадцатой | События кэшируются на текущий такт |
| Неиспользуемый analyser в выходном тракте | Удалён |
| Аудиотест подменял Effects целиком | Тестируется настоящий модуль Effects с записывающей имитацией Web Audio |
| README описывал в основном кнопки | Добавлены запуск, команды, карта файлов, архитектура и инструкции по расширению |

## Проверка сохранности

Контрольная сумма музыкальных данных зафиксирована до рефакторинга. Тест переводит новые события обратно в исходный формат и сверяет все 21 паттерн целиком: позиции, высоты, длительности, тембры и velocity. Исходные визуальные ресурсы и значения CSS сохранены с переносом в новые каталоги.

Набор автоматических проверок охватывает музыкальные данные, Shuffle, очереди изменений, Solo, BPM, ошибки запуска, быстрый перезапуск, завершение источников, маршрутизацию эффектов и события UI. Проверка сборки сверяет все файлы `src`/`dist`, синтаксис JS и существование локальных ресурсов.

## Ограничения проверки

DOM и Web Audio в тестах имитируются. Эти тесты проверяют команды, соединения и состояние, но не заменяют прослушивание, замер громкости и визуальную проверку в браузере. Общие хвосты эффектов после Solo могут затухать ещё некоторое время. Экспорт аудио, MIDI, сохранение сессии и загрузка сэмплов пока не реализованы.
